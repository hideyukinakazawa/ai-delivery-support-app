# AI配送業務支援アプリ

配送に関する問い合わせメールを分類し、配送日・時間帯の確認と返信メール下書きの作成を支援するプロトタイプです。<dr>
最終的な判断・返信内容の修正・送信は、配送担当者が行います。

## 処理の流れ

```text
問い合わせ本文
→ ファインチューニング済みBERTによる4分類
→ 正規表現による希望日・希望時間帯の抽出
→ 返信メール下書きの生成
→ 担当者による確認・編集・送信
```

## 主な機能

- 問い合わせ本文の入力
- BERTによる配送希望の4分類
- 分類ラベルと確信度の表示
- 希望配送日・希望時間帯の抽出
- 抽出結果に応じた返信メール下書きの生成・編集
- 低確信度の場合の確認メッセージ表示

## 分類ラベル

| ラベル | 内容 |
|---|---|
| 希望配送日あり | 希望日または曜日のみがある |
| 希望配送時間帯あり | 希望時間帯のみがある |
| 希望配送日時あり | 希望日・曜日と希望時間帯の両方がある |
| 希望日時なし | 配送日時の指定がない |

## 使用技術

- Python
- PyTorch / BERT
- FastAPI
- Streamlit

## 実行方法

2つのターミナルでAPIと画面を起動します。

```powershell
# ターミナル1
fastapi dev api.py
```

```powershell
# ターミナル2
streamlit run app.py
```

## 注意事項

- 公開リポジトリにはダミーデータのみ。
- 実際の問い合わせメール、APIトークン、保存済みBERTモデルは含めていません。
- ダミーデータによる動作確認であり、実業務での精度を示すものではありません。
