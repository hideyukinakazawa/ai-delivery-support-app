# ai-delivery-support-app

## 概要

配送に関する問い合わせメールをAIで分類し、配送担当者の確認・判断を支援するプロトタイプです。  
業務のペーパーレス化を出発点とし、Re:lationで管理する問い合わせへの活用を想定。

## 目的

- メール本文をBERTで配送希望の4種類に分類
- 希望日・時間帯の確認や返信下書き作成を支援
- AIは自動送信せず、担当者が最終確認・送信

## 分類ラベル

- 希望配送日あり
- 希望配送時間帯あり
- 希望配送日時あり
- 希望日時なし

## データ・技術

- `generate_dummy_inquiries.py` からCSVを生成 
- Python,Streamlit,BERTを使用
- Re:lation API連携は、BERT分類の実装後に追加する予定
