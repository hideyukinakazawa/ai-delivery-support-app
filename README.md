# AI配送業務支援アプリ

配送に関する問い合わせメールを分類し、配送日・時間帯の確認と返信メール下書きの作成を支援するプロトタイプです。  
最終的な判断・返信内容の修正・送信は、配送担当者が行います。

## 処理の流れ

```text
問い合わせ本文
→ ファインチューニング済みBERTによる4分類
→ 正規表現による希望日・希望時間帯の抽出
→ 返信メール下書きの生成
→ 担当者による確認・編集・送信
```

## 主な機能

- 問い合わせ本文の入力
- BERTによる配送希望の4分類
- 分類ラベルと確信度の表示
- 希望配送日・希望時間帯の抽出
- 抽出結果に応じた返信メール下書きの生成・編集
- 低確信度の場合の確認メッセージ表示
- モック案件の作業フェーズ・チェックリストの表示とクローズ操作

## 分類ラベル

| ラベル | 内容 |
|---|---|
| 希望配送日あり | 希望日または曜日のみがある |
| 希望配送時間帯あり | 希望時間帯のみがある |
| 希望配送日時あり | 希望日・曜日と希望時間帯の両方がある |
| 希望日時なし | 配送日時の指定がない |

## 返信下書きと配送時間帯

抽出した希望日・希望時間帯を、担当者が編集できる返信メール下書きへ反映します。下書きは自動送信されません。

ヤマト運輸の配送時間帯は、次の区分に正規化して扱います。

| 時間帯 |
|---|
| 午前中 |
| 14:00-16:00 |
| 16:00-18:00 |
| 18:00-20:00 |
| 19:00-21:00 |

全角・半角の違いや「14時から16時」などの表記ゆれを吸収します。一方、「午後」など区分を特定できない表現は自動で確定せず、担当者が確認します。

## 使用技術

- Python
- PyTorch / BERT
- FastAPI
- Streamlit
- Google Sheets（モック案件の作業履歴）

## 実行方法

2つのターミナルでAPIと画面を起動します。

```powershell
# ターミナル1
fastapi dev api.py
```

```powershell
# ターミナル2
streamlit run app.py
```

## 注意事項

- 公開リポジトリにはダミーデータのみを置いています。
- 実際の問い合わせメール、顧客情報、APIトークン、OAuth認証情報、保存済みBERTモデルは含めていません。
- ダミーデータによる動作確認であり、実業務での精度や効果を示すものではありません。
- AIの結果は補助情報です。配送可否の判断、返信内容の修正、送信は必ず担当者が行います。
