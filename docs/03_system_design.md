# システム設計

## 構成

```
問い合わせメール
  ↓
Streamlit
  ↓
BERTによる4分類
  ↓
生成AIによる希望日時抽出・返信下書き
  ↓
担当者が確認・送信
```

## 役割

|要素|役割|
|---|---|
|Streamlit|入力と結果表示|
|BERT|配送希望の分類|
|生成AI|希望日時の抽出、返信下書き作成|
|人|出力確認、修正、送信判断|

## Re:lation API連携

初期版では連携しない。追加時は、受信箱・チケット・メッセージを取得し、`body` をモデルへ渡す。返信下書き登録には `message_id` を使用する。

アクセストークンと実データは環境変数で管理し、公開リポジトリには含めない。
