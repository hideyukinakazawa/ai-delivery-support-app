# システム設計

## 現在のシステム構成

| 要素 | 役割 |
|---|---|
| Streamlit（`app.py`） | 問い合わせ本文の入力、分類・抽出結果の表示、返信下書きの編集 |
| FastAPI（`api.py`） | BERT推論API、希望日・希望時間帯の正規表現抽出 |
| 保存済みBERTモデル | 問い合わせ本文を4分類 |
| 担当者 | 分類・抽出・下書きを確認し、修正後に送信 |

### 処理フロー

```text
問い合わせ本文
→ Streamlit
→ FastAPI
→ ファインチューニング済みBERTで4分類
→ 希望日・時間帯を抽出
→ Streamlitで結果・警告・返信下書きを表示
→ 担当者が確認・編集・送信

## Re:lation API連携

初期版では連携しない。追加時は、受信箱・チケット・メッセージを取得し、`body` をモデルへ渡す。返信下書き登録には `message_id` を使用する。

アクセストークンと実データは環境変数で管理し、公開リポジトリには含めない。
