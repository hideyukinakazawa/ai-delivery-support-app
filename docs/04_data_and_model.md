# データとモデル

## データ

`generate_dummy_inquiries.py` から `dummy_inquiries.csv` を生成する。

|列|内容|
|---|---|
|`subject`|件名|
|`body`|本文|
|`label`|正解ラベル|

BERTの入力には `body` を使用する。初版は各ラベル20件、計80件を目標とする。

## 分類ラベル

|ID|ラベル|条件|
|---|---|---|
|0|希望配送日あり|日付・曜日のみ|
|1|希望配送時間帯あり|時間帯のみ|
|2|希望配送日時あり|日付・曜日と時間帯の両方|
|3|希望日時なし|日時指定なし|

## 学習と評価

日本語BERTを4クラス分類としてファインチューニングする。  
欠損・重複・ラベル数を確認し、学習用と検証用に分割する。Accuracy、Macro F1、混同行列で評価する。

### 初回評価結果（2026/08/22）

- データ数：82件（学習65件、検証17件）
- Accuracy：0.941
- Macro F1：0.937
- 誤分類：1件  
  「平日の14:00-16:00であれば受け取り可能です。」を  
  「希望配送日時あり」ではなく「希望配送時間帯あり」と予測

## 留意点

すべて架空のデータを用いる。80件規模の結果は、実業務での性能や削減効果を示すものではない。
