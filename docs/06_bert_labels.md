# BERT分類ラベル

## 分類対象

BERTへの入力

- 件名
- 本文

BERTの出力

- 問い合わせカテゴリ

---

# 分類ラベル

|ラベルID|分類名|概要|
|---|---|---|
|0|配送日時変更|配送日時の変更依頼|
|1|配送先変更|住所・配送先変更|
|2|新品交換|新品交換に関する依頼|
|3|同時回収|同時回収の依頼|
|4|発送状況確認|発送状況の問い合わせ|
|5|修理状況確認|修理進捗の問い合わせ|
|6|キャンセル|発送・修理キャンセル|
|7|その他|上記に該当しない問い合わせ|

---

# 問い合わせ例

|問い合わせ例|分類ラベル|  
  
|配送日を変更したいです|配送日時変更|  
|届け先住所を変更してください|配送先変更|  
|新品へ交換できますか？|新品交換|  
|同時回収をお願いします|同時回収|  
|発送されましたか？|発送状況確認|  
|修理は終わっていますか？|修理状況確認|  
|キャンセルしたいです|キャンセル|  

# AI分類結果の利用

BERTで分類した結果は担当者へ表示する。

例

AI分類

- 配送日時変更
- 同時回収
- 修理状況確認

担当者は分類結果を参考に問い合わせ内容を確認し、
必要に応じてその日のチェックリストに沿って作業を進める。
