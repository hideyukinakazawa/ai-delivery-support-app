# Re:lation API

## 利用目的

- Re:lationから問い合わせ情報を取得する
- 問い合わせ内容をBERTへ入力する
- AIによる分類結果をチェックリストへ反映する

## 利用予定API

- 問い合わせ一覧取得
- 問い合わせ詳細取得

※利用するAPIは実装段階で最終決定する。

## 利用するデータ項目

|項目|用途|
|---|---|
|メールアドレス|問い合わせ検索・顧客識別|
|件名|問い合わせ一覧表示|
|本文|BERTによる分類|
|送受信日時|問い合わせ履歴表示|
|問い合わせID|内部管理用|

## BERTへ入力する項目

- 件名
- 本文

これらの情報を入力として問い合わせ内容を分類する。

## 分類結果（予定）

- 発送前・事前準備
- 発送前・配送準備
- 発送前・梱包
- 倉庫発送後・Re:lation連絡
- 倉庫発送後・スマレジ登録

## 認証方式

- API Token認証を利用する
- API TokenはGitHubへ保存しない
- APIリクエスト時はAuthorizationヘッダーを利用する（詳細は実装時に確認）

## 基本エンドポイント

https://<subdomain>.relationapp.jp/api/v2/

- 利用するAPIに応じて各エンドポイントへアクセスする。
