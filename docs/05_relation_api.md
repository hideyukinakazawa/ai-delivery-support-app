# Re:lation API

## 利用目的

- Re:lationから問い合わせ情報を取得する
- 問い合わせ内容をBERTへ入力する
- AIによる分類結果をチェックリストへ反映する

---

## 利用予定API

- 問い合わせ一覧取得
- 問い合わせ詳細取得

※利用するAPIは実装段階で最終決定する。

---

## 利用するデータ項目

|項目|用途|
|---|---|
|メールアドレス|問い合わせ検索・顧客識別|
|件名|問い合わせ一覧表示|
|本文|BERTによる分類|
|送受信日時|問い合わせ履歴表示|
|問い合わせID|内部管理用|

---

## BERTへ入力する項目

- 件名
- 本文

これらの情報を入力として問い合わせ内容を分類する。

---

## 分類結果（予定）

- 発送前・事前準備
- 発送前・配送準備
- 発送前・梱包
- 倉庫発送後・Re:lation連絡
- 倉庫発送後・スマレジ登録

---

## 認証方式

Re:lation APIではAPI Token認証を利用する。

---

## 制限事項

- APIにはレートリミットが設定されている。
- 実装時はAPI仕様書に従ってアクセスする。
- 個人情報を含む問い合わせ内容はGitHubへ保存しない。
